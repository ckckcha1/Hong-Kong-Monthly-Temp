# Hong Kong Temperature Heatmap

CSCE 679 Data Visualization: year/month heatmap of Hong Kong's daily temperature data, built with React and D3

## Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (includes npm)

### Install and run

```bash
npm install
npm start
```
